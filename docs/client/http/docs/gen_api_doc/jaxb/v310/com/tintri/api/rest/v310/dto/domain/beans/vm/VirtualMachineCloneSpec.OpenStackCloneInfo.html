Name: OpenStackCloneInfo

OpenStack specific information if the clone operation involves OpenStack VMs

Data Structure
{
   "typeId": "com.tintri.api.rest.v310.dto.domain.beans.vm.OpenStackCloneInfo",
   "cloneDirectoryPath": <String>,
}
Attributes
NameTypeDescription
cloneDirectoryPathxsd:stringPath of directory where cloned files will be placed. Path is relative to /tintri. E.g. cloneDirectoryPath = 'vm-clone' will clone the files into /tintri/vm-clone-<n>, where n starts with 1. For every clone operation that uses same cloneDirectoryPath of 'vm-clone', the n will be incremented by the clone count each time.
